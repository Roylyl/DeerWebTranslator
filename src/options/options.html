翻译设置

像 Chrome 原生翻译一样顺手：默认把网页可见英文快速替换为中文，也可以随时切换为双语对照。

供应商与模型

选择一个供应商，再选择预设模型或填写自定义模型。

OpenAI-compatible

预设模型仅作快捷选项；模型供应商有更新时可直接填写新模型名。

扩展会在后台 service worker 中拼接对应的 API endpoint。自定义地址首次保存时，Chrome 可能会请求网站访问权限。

Key 按供应商分别保存在扩展的 chrome.storage.local 中，不会发送给网页内容脚本。

翻译偏好

这些设置会进入后台生成的翻译提示词。

扩展会在你的提示词之后追加不可缺少的 JSON、技术术语与“只翻译”约束。

每行一个“原文 = 译文”映射，只发送当前文本命中的条目以节省 token；自由格式规则会完整保留。

连接测试会向当前已保存的模型发送一条简短测试文本，可能消耗少量 API 额度；不会发送正在浏览的网页内容。

本地翻译缓存

读取缓存信息…

会清除各版本的扩展翻译缓存，无法撤销；下次访问可能需要重新翻译。

隐私与安全

API Key 保存在本地扩展存储，仅可信扩展页面和后台可访问；弹窗只保留是否已配置的状态，后台用于请求鉴权。content script 不读取 Key，网页脚本也不会收到 Key。网页正文会发送到你选择的模型供应商，请不要翻译机密信息。
